Dapat file undangan.apk? Jangan dibuka.

OJK dan BI mengingatkan modus file APK yang menyamar jadi undangan atau foto di WhatsApp. Kalau dipasang, file itu bisa membuka akses ke HP kamu, termasuk aplikasi bank.

✓ Jangan pasang file .apk dari chat
✓ Jangan bagikan PIN, password, atau OTP ke siapa pun
✓ Telanjur klik? Hubungi bank lewat nomor resmi dan lapor ke Kontak OJK 157

Pernah dapat file aneh di WA? Jawab ya atau tidak di komen. Kirim ke orang tuamu sekarang.
